# Contributing to Nuerolynx

Changes should preserve Flipper Zero compatibility, keep the NLX device-facing identity consistent, and retain required upstream authorship and licensing notices.

Before submitting a change:

1. Build `dist_updater_package` successfully.
2. Check that the generated update archive is readable.
3. Verify the boot artwork, About screen, Nuerolynx settings app, and status bar on hardware.
4. Do not remove third-party license or author credits.
