# Upstream attribution

Nuerolynx Firmware v1.1 is a modified distribution derived from Momentum Firmware, which in turn includes work from Flipper Devices and many independent application and protocol authors.

- Upstream project: https://github.com/Next-Flip/Momentum-Firmware
- Upstream base commit: `d3f89dfe2`
- License: GNU General Public License v3.0; see `LICENSE`

Nuerolynx changes the device-facing firmware identity, artwork, defaults, menu labels, update artwork, and status-bar behavior. Internal source identifiers and compatibility defines inherited from upstream may remain where renaming them would break APIs, saved settings, or bundled applications. Those identifiers are implementation details and do not represent the device-facing brand.
